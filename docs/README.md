# Documentação do ArborGrid

Esta pasta reúne os artefatos de apoio exigidos para explicar o MVP de RPA:

- [`fluxo-rpa.md`](fluxo-rpa.md): fluxograma do processo ponta a ponta.
- [`PDD.md`](PDD.md): descrição do processo, entradas, regras e saídas.

Os diagramas usam Mermaid e podem ser visualizados no GitHub ou em um editor
compatível com Mermaid.
