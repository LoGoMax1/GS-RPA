# Logs de demonstração

Os arquivos desta pasta documentam as execuções do MVP. O arquivo
`execucoes.log` é atualizado automaticamente a cada ocorrência processada pelo
site ou pelo comando unificado. Não contém dados pessoais, credenciais ou
informações de cidadãos.

O histórico completo das execuções locais fica no SQLite `rpa_demo.sqlite3`,
que é gerado em tempo de execução e permanece no `.gitignore`.
